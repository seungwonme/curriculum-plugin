# 실제 수업 전달 회고

진행된 수업의 녹화·녹음·전사와 계획안을 대조해 다음 회차에서 바꿀 행동을 정한다. 요약문만으로 판단하지 않고 원본 시간축에 연결된 근거를 남긴다.

## 1. 입력 확정

1. 대상 날짜·회차와 계획안·강사 큐시트를 확인한다.
2. 녹화·녹음 후보를 모두 나열하고 수업 본편, 휴식, 준비·기획 기록을 구분한다.
3. 포함·제외한 파일과 이유를 기록한다.
4. 파일별 재생 시간과 전사 범위를 확인한다.
5. 분할 파일은 재생 순서대로 놓고, 앞 파일의 재생 시간을 더해 누적 시작·종료 시각을 기록한다. 실제 공백·중복 구간이 확인되면 그대로 표시하고 임의로 메우지 않는다.

분할 파일이 있으면 다음 표를 먼저 만든다.

| 파일 | 원본 시간축 | 전체 수업 누적 시간축 |
|---|---|---|
| `part-1.mp4` | `00:00:00-00:55:00` | `00:00:00-00:55:00` |
| `part-2.mp4` | `00:00:00-00:48:00` | `00:55:00-01:43:00` |

전사가 없거나 품질이 낮으면 가능한 구간은 원본으로 직접 확인한다. 원본도 확인할 수 없는 구간은 `확인 불가`로 남기고 추측하지 않는다.

## 2. 계획과 실제 시간축 대조

계획안의 주요 구간마다 실제 시작·종료 타임스탬프를 연결한다.

| 차원 | 확인할 것 |
|---|---|
| 순서 | 계획한 개념·시연·실습·결과 확인 순서가 유지됐는가 |
| 시간 | 구간별 계획 시간과 실제 시간이 얼마나 달랐는가 |
| 실습 | 수강생이 직접 수행하고 결과를 확인할 시간이 보장됐는가 |
| 질문 | 반복 질문, 침묵, 재설명에서 막힌 지점이 드러나는가 |
| 산출물 | 약속한 결과물이 수업 안에서 완성·확인됐는가 |
| 이월 | 시간 부족으로 생략하거나 다음 회차로 넘긴 내용이 무엇인가 |
| 운영 | 환경·권한·보안·파일 준비 문제로 흐름이 끊겼는가 |

이론이 실습을 밀어냈다면 이론을 유지한 채 시간을 늘리는 안보다 삭제·축약·사전자료 이동을 먼저 검토한다. 다음 회차의 실습과 결과 확인 시간을 보호하기 위해서다.

## 3. 발견 작성

각 발견을 다음 형식으로 쓴다.

```markdown
- [심각도] 차원
  - 근거: `part-2.mp4` 00:12:10-00:17:35 (전체 수업 01:07:10-01:12:35), 실제 발화·행동 요약
  - 계획: 계획안의 해당 구간과 예정 시간
  - 실제 영향: 실습·이해·산출물에 생긴 결과
  - 다음 변경: 삭제·축약·이동·순서 변경·안내 보강 중 하나
```

근거에는 파일명과 원본 타임스탬프를 항상 적는다. 분할 파일이면 전체 수업 누적 시간도 함께 적는다. 감상이나 성격 평가는 제외하고 타임스탬프와 계획안으로 검증할 수 있는 전달 문제만 남긴다.

## 4. 다음 회차 변경안

변경안은 실행 가능한 단위로 정리한다.

- **삭제·축약**: 줄일 설명과 확보되는 시간을 적는다.
- **사전 이동**: 수업 전에 볼 자료와 수업 중 확인 방법을 적는다.
- **순서 변경**: 옮길 구간과 바뀐 학습 흐름을 적는다.
- **실습 보호**: 실습 시작 시각과 최소 결과 확인 시간을 적는다.
- **운영 보강**: 사전 점검할 계정·권한·파일·보안 조건을 적는다.

사용자가 교안 수정까지 요청한 경우에만 변경안을 `references/review.md`의 교안 개선 하네스로 넘긴다.

## 5. 출력 템플릿

```markdown
# [회차] 실제 수업 전달 회고

## 입력과 범위
- 계획안:
- 포함한 녹화·녹음:
- 제외한 파일과 이유:
- 확인하지 못한 구간:

## 분할 파일 시간축
| 파일 | 원본 시간축 | 전체 수업 누적 시간축 |
|---|---|---|

## 계획 대비 실제 흐름
| 구간 | 계획 시간 | 파일명·원본 타임스탬프 | 전체 수업 누적 시간 | 차이 | 영향 |
|---|---:|---|---:|---:|---|

## 잘 유지할 것
- 근거가 연결된 강점

## 바꿀 것
- 심각도·근거·영향·다음 변경

## 다음 회차 시간표
| 구간 | 변경 | 확보·사용 시간 | 종료 확인 |
|---|---|---:|---|

## 이월·미확인
- 다음 회차로 넘긴 내용과 확인 불가 항목
```
